MATRIX ACADEMY

Every solver has a strategy.

Quick lessons to turn row reduction into a series of small decisions.

①

Find a pivot

A pivot is the first nonzero entry in a nonzero row. In RREF, each pivot is 1 and is the only nonzero entry in its column.

Start on the left. Find a useful nonzero entry and move it into place if needed.
⇅

Swap rows

Exchange two complete rows without changing the solution set.

If your pivot spot is zero, look below it for a row you can swap into place.
×

Scale a row

Multiply every entry in a row by the same nonzero number to turn a pivot into 1.

If the pivot is 2, multiply the whole row by 1/2.
＋

Eliminate an entry

Add a multiple of one row to another to make a chosen entry zero. Apply it to every entry in the target row.

If a row has 2 under a pivot 1, subtract twice the pivot row.
▦

Know when you're done

Zero rows go at the bottom, leading 1s move right as you go down, and each pivot column has zeros everywhere else.

⌛

Play efficiently

Plan the next pivot before moving. Undo can help you test a strategy.

A short solution often comes from clearing a pivot column completely before moving on.

Quick reference

Type 1 — Swap rows: R₁ ↔ R₂

Exchange the entire rows.

Type 2 — Scale: R₁ → kR₁

Multiply every entry in one row by the same nonzero number k.

Type 3 — Row replacement: R₁ → R₁ + kR₂

Add a multiple of the source row to the target row. The source row stays the same.
